# dzzzr-mock — mock-сервер движка Dozor Classic

`dzzzr-mock` повторяет протокол боевого движка «Дозор Классик» настолько, чтобы
библиотека `dzzzr` и утилита `dzzzr` работали против него без сети. 

Сервер держит всё состояние в памяти, поэтому перезапуск возвращает игру в
исходное положение.

## Запуск

```
go run ./cmd/dzzzr-mock
```

| Флаг / переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `-addr`, `DZZZR_MOCK_ADDR` | `0.0.0.0:18090` | адрес прослушивания |
| `-city` | `moscow` | сегмент города в путях |
| `-quirks`, `DZZZR_MOCK_QUIRKS` | — | странности движка через запятую, см. ниже |
| `-version` | — | напечатать версию и выйти |

Каждый запрос пишется одной строкой в stderr.

Базовый URL для клиента: `http://127.0.0.1:18090/moscow/`.

```
dzzzr login -base-url http://127.0.0.1:18090/moscow/ -login demo -password demo -captain demo -pin 1234
dzzzr status -base-url http://127.0.0.1:18090/moscow/
dzzzr send-code 1 -base-url http://127.0.0.1:18090/moscow/
```

## Что находится внутри

Игра 4242 «Тестовая игра», старт за час до запуска процесса. Команда
«MockTeam» (id 5150), капитан `demo`, PIN `1234`.

| Уровень | Основные коды | Прочее |
| --- | --- | --- |
| 1 | `1`, `2`, `3` (нужны все) | бонусный код `B1` (10 мин), ложный код `FAKE` (штраф 10 мин), спойлер `SP1` (штраф 5 мин), секторы «Гаражи» и «Пустырь» |
| 2 | `4`, `5` (достаточно одного) | универсальный код запрещён |
| 3 | `6` | последний уровень: после него игра завершается |
| 4 | `SK1` | сквозное бонусное задание, 15 бонусных минут |

Универсальный код игры — `MASTER`. Подсказки выдаются через 30 и 60 минут
после выдачи уровня (интервалы 30/30/30), поэтому на первом уровне обе
подсказки уже видны сразу после запуска.

## Авторизация

`API/login.php` защищён HTTP Basic: имя пользователя — `{city}_{captain}`,
пароль — PIN. Подходит любой капитан с PIN `1234`; без заголовка сервер
отвечает 401 и конвертом `{"error" : "Ошибка авторизации. Не введено имя
капитана"}`, с неверным PIN — 401 и конвертом про неверный ПИН.

Сам вход принимает любую пару логин/пароль, кроме `fail`/`fail` (код 4);
без одного из параметров — код 6. Успех отдаёт `code: "2"` и токен из 32
заглавных латинских букв.

Остальные точки входа требуют параметр `s` с этим токеном. Неизвестный токен
даёт HTTP 200 и конверт `{"error" : "Ошибка авторизации. Неверный
идентификатор сессии"}` — именно так ведёт себя `API/APIconst.php`.

Права капитана привязаны к логину сессии: действия `abandon`, `break`,
`takeClue`, `send_message` и другие управляющие команды от чужого логина
возвращают код 57.

## Точки входа

| Метод и путь | Что делает |
| --- | --- |
| `GET /{city}/API/login.php` | вход, выдача токена сессии |
| `GET /{city}/go/?api=true&s=` | состояние игры в форме `go.tpl` |
| `POST /{city}/go/?api=true&s=` | действия движка, ответ — редирект `?err=N` |
| `GET /{city}/API/game.php?stat=true` | таблица времён по уровням |
| `GET /{city}/API/game.php?log=true` | лог команды |
| `GET /{city}/API/game.php?level=1` | разбор текущего уровня для ботов |
| `GET /{city}/API/game.php?bonuslevel=1` | то же для сквозных заданий |
| `POST /{city}/API/game.php` | прокси действия, ответ `{"err":N}` |
| `GET /{city}/API/messages.php?after=` | чат команды и сообщения организатора |
| `POST /{city}/API/postmessage.php` | сообщение в чат команды |
| `GET /{city}/API/gamesList.php` | список игр города, без авторизации |

Ответ `go/` полностью повторяет форму шаблона: числа приходят строками,
отсутствующий уровень выглядит как `{ }`, а список `bonusLevels` всегда
заканчивается таким же пустым объектом.

POST без `api=true` и без реферера с `dzzzr.ru` движок игнорирует: сервер
отвечает редиректом без кода.

## Код `PZDC` — имитация потери связи

Отправка кода `PZDC` держит соединение открытым 60 секунд, затем отвечает
502. Всё это время сессия считается «без сети»: каждый её запрос ждёт до
двух секунд и тоже получает 502. Так удобно проверять, как клиент переживает
обрыв связи. Длительности задаются пакетными переменными
`networkDownDuration` и `networkDownSleep`, тесты их укорачивают.

## Тесты

```
go test ./cmd/dzzzr-mock/ -count=1
```

Тесты поднимают mock через `httptest` и ходят к нему настоящим клиентом
`dzzzr`, поэтому проверяют и сервер, и совместимость с библиотекой.

## Административная часть

`/{city}/admin/` защищён HTTP Basic с логином `admin` и паролем `admin` —
это отдельная от игровой учётная запись, как и на боевом движке. Страницы
отдаются HTML-ом, каждая запись — POST с полем `action` и ответом-редиректом.

| Путь | Что отдаёт |
| --- | --- |
| `?action=games` | список игр и форма настроек (`update_game`, `add_game`, `del_games`, `copy_game`) |
| `?action=zadanie&categoryValue=` | список уровней и форма уровня (`add_zadanie`, `update_zadanie`, `del_zadanie`, `copy_zadanie`) |
| `?action=teams&categoryValue=` | команды игры и форма заявки (`updateTeam`, `acceptAllApplications`, `GeneratePinCodes`, `addTeamToGame`, `del_application`, `newTeam`) |
| `gmAdmin.php?finished=` | экран мониторинга и вмешательства организатора |
| `lookLog.php?gmid=&lastTime=` | свежие события, упакованные в параметр `opt` мета-обновления |
| `gmcht.php?gm=` | переписка организатора с командами |

Идентификатор уровня в админке (`id`) намеренно отличается от его номера
(`order_p`): изначально он равен `900 + номер`, но при перемещении задания
остаётся прежним, как и на боевом движке, — меняется только номер. Клиент,
перепутавший их, сломается тут так же, как сломался бы на движке.

Вмешательства на `gmAdmin.php`: `newlevel`, `acceptLevel`,
`newLevelAndAccept`, `code`, `delLevel`, `removeLevel`, `delstat`, `bonus`,
`delBonus`, `stop`, `start`, `switchRobot`, `finishGame`, `chtime`.

Время в логе округляется до секунды, потому что движок хранит его в колонке
MySQL `DATETIME`, а опрос лога сравнивает именно с такой точностью.

## Странности движка (`-quirks`)

Обычный запуск отдаёт хорошо себя ведущую игру — этого хватает почти всем
тестам. Но часть поломок боевого движка живёт в состояниях, до которых
фиксированный сценарий не доходит: сквозное задание в основном слоте, команда
без игры, остановленный движок. Каждое из них ломало живого клиента, поэтому
их можно включить по имени — и проверка исправления перестаёт держаться на
одной фикстуре.

```
dzzzr-mock -quirks skvoz-current,noise
```

| Имя | Что воспроизводит |
| --- | --- |
| `noise` | отладочный дамп в HTML-комментарии перед JSON, как в demo-городе |
| `skvoz-current` | сквозное задание в основном слоте, из-за чего `go_level.tpl` дописывает вторую запятую и ответ становится `},,` |
| `nogame` | `templates/JSON/go_nogame.tpl`: `{"error": 2, "errorText": …}` с кодом 200 |
| `stopped` | `API/game.php` отдаёт `{"err":13}` и выходит, пока движок выключен организатором |
| `empty-level` | `API/game.php?level=1` отвечает 200 и пустым телом |
| `choose-level` | заполненный `NextLevelSelector` — форма выбора уровня |
| `level-finished` | время на бонусные коды после последнего основного (`bonusAfter` 3, а не -1): уровень остаётся текущим с `isLevelFinished` `"1"`, а последний основной код отвечает кодом 41 |
| `silent-refusal` | отказ в `abandon` без единого кода результата, как при пустом `canAbandon` |
| `selected-level-zero` | список заданий печатает «0.» вместо номера у задания, открытого в редакторе; настоящая позиция остаётся в его `order_p` |
| `unclosed-form` | форма создания команды не закрыта, из-за чего карточка команды исчезает из дерева разбора: по стандарту HTML тег `<form>` игнорируется, пока предыдущая форма открыта |
| `admin-no-access` | `admin/?action=teams`, `admin/lookLog.php` и `admin/gmcht.php` отвечают 200 и текстом «Вы не имеете доступа к этому разделу», как для верного логина организатора, не назначенного организатором именно этой игры |

Неизвестное имя — ошибка запуска, а не тихий откат к обычному режиму: иначе
тест прошёл бы по неверной причине.

## Архив игры

Mock отдаёт архив текущей игры 4242:

- `?section=arc` — список с ссылками на игру.
- `?section=arc&gmid=4242&what=stat` — публичная таблица по текущему прогрессу.
- `?section=arc&gmid=4242&what=comment` — шапка всем, задания капитану `demo`.
- `gameLogJSON.php?gmid=4242` — журнал событий в формате нумерованных строк,
  первая строка содержит заголовки, включая две колонки «Данные».

Сценарий и лог проверяют cookie `dozorSiteSession`, содержащий токен входа
через API. Один параметр `s` не даёт доступа. Без прав экспорт лога отвечает
HTTP 200 с пустым телом. Неизвестный ID игры возвращает 404. Архив читает
текущее состояние mock: ввод кода добавляет событие, завершение уровня
обновляет время в таблице. Статистика во время игры содержит завершённые
уровни; место появляется после финиша.

```sh
dzzzr -base-url http://127.0.0.1:18090/moscow/ game-stat 4242 -levels
dzzzr -base-url http://127.0.0.1:18090/moscow/ game-desc 4242
dzzzr -base-url http://127.0.0.1:18090/moscow/ game-log 4242
```
