Загрузка Go-модуля…

Файлы обрабатываются в этой вкладке. Агент отправляет выбранные инструментами данные вашему LLM-провайдеру. Авторизация и публикация в движок доступны в локальном dzzzr web.

Поиск по журналу

Сначала загрузите журнал во вкладке «Статистика». Фильтры объединяются; время — часы движка.



Файлы и PDF
Загрузите PDF, JSON или текст. Файлы доступны агенту по имени только в этой вкладке. После перезагрузки загрузите их заново.
    

    

    Игры и черновики сохраняются в этом браузере. Экспортируйте JSON для переноса и резервной копии.
    

    

    Сценарии JSON
    Редактируйте полный сценарий или пакет уровней в исходном JSON. Проверка использует Go-схемы CLI. HTML заданий и вложения сохраняются; публикация в движок здесь не выполняется.
    

    Агент
    Общее ядро агента CLI: журналы, PDF, сценарии и совместное редактирование черновиков. Ключ хранится только в памяти вкладки. Провайдер должен разрешать браузерные запросы (CORS).
